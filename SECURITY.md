# Security policy

Report vulnerabilities privately through GitHub security advisories, following [Websonette's policy](https://github.com/Websonette/.github/blob/main/SECURITY.md). Do not publish credentials or production records in an issue.

This package is pre-1.0. Security fixes target the latest release. Read `docs/security.md` before deploying. HTTPS, an authenticated consent adapter and private OAuth key storage are required for production.
